## 2026-11-08 拼音候选搜索后端化

- **Changed**：角色、音乐和 CP 成员选择统一通过新候选 ID 搜索接口匹配名称、别名和主作品／专辑；前端保留已选项处理、筛选与日期排序。
- **Added**：搜索等待与失败提示、64 字输入限制；忽略过期响应，清空输入立即恢复原列表。

- **迁移 / 配置**：无数据库迁移、代理或配置变更；两个同名功能分支仅本地实现，未部署。
